# DSE 志愿填报助手

> 填志愿前，先搞清楚一件事：**我这个分，到底能报哪些学校的哪个专业。**

内地有 165 所高校招收香港 DSE 考生，专业加起来近 3800 个。官方只给一本厚指南（PDF），翻起来很痛苦 —— 你要在几百页里找"我这个分数能报哪里"。

这个小工具把它变成了对话：**你用自己的话问，它给你具体的学校、专业和分数，还告诉你答案在指南第几页。**

## 你可以这样问

**「我 4/3/4 想去广东读计算机」**

```
华南理工大学[985]｜（计算机科学与工程学院）计算机类｜最低 11 / 最高 15（卡线）
暨南大学[211]｜（国际学院）计算机科学与技术｜最低 9 / 最高 17（低你 2 分）
深圳大学[普通]｜（计算机与软件学院）计算机科学与技术｜最低 11 / 最高 14（卡线）
```

**「校长推荐计划有什么要求」**

```
按《教育部_2026招生办法》原文：……
（回答里带文件名和条款，你可以照着去核对）
```

**「广东省有哪些专业可以报」**

```
广东共 731 个专业，先给你看 20 个（跨 15 所学校）。
告诉我你的三科成绩、想去的学校或专业，我能缩到你能报的范围 ——
比如问「中山大学临床医学多少分」「华南理工计算机多少分」最准。
```

> 结果太多时它不会硬塞给你几百条，而是先给个大概，再问你要不要缩小范围。

## 它能帮你解决三类事

| 你想知道 | 它会做 |
|---|---|
| 我这个分数能报什么 | 按你的三科成绩筛出"能报"的专业，标出你差几分、稳不稳 |
| 某校某专业要多少分 | 给出最低分、最高分，以及指南里的页码（可回查原文） |
| 政策是怎么规定的 | 从官方文件里找原文回答，**带出处**，不是凭印象说 |

**它不会做的事**：不替你选志愿、不推荐"该报哪个" —— 它只把事实摆清楚，决定权在你。

## 为什么可以信

市面上的 AI 问答最容易出的问题，是**把分数编出来**。这个工具专门防这个：

- **分数不是模型生成的**。模型只负责听懂你在问什么，真正的查询由数据库完成，它连"13 分"这个数字都不用自己算。
- **政策回答必须引用原文**。不允许"凭训练记忆"回答，回答里必须能指出出自哪份文件。
- **查不到就说查不到**。如果它的回答里出现了具体分数，但这一轮根本没查数据库，系统会把它拦下来重查。

## 跑起来

需要：Python 3.11+、PostgreSQL 14+、Node 18+，以及一个阿里云百炼（或 DeepSeek）的 API Key。

```bash
cd dse-agent
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env     # 填 DASHSCOPE_API_KEY / DEEPSEEK_API_KEY / PG_*

python scripts/load_data.py                          # 建表并导入 3794 条记录
cd frontend && npm install && npm run build && cd ..

python -m uvicorn app.server:app --port 8000
```

打开 http://localhost:8000 就能用。

技术栈：Python 3.11 · FastAPI · LangGraph（ReAct）· LangChain · PostgreSQL · RAG · SSE · Vue 3 + Vite

### 三个关键设计

| 设计 | 解决什么 |
|---|---|
| **确定性工具 + 模型转述** | 模型只输出结构化参数，筛选排序全部由参数化 SQL 完成 —— 分数不由模型生成 |
| **answer_guard 护栏** | 检测「问分数、却没查库、回答却有具体分数」时强制重查（最多 2 次） |
| **分层记忆** | 模型只输出本轮增量，代码维护精确查询条件 —— 避免模型复述历史时抄错数字 |

### 评测

54 条用例覆盖 8 个能力维度，全部用**确定性断言**（工具是否调用、是否泄漏具体分数、是否命中关键词），不依赖 LLM 打分：

| 维度 | 通过 | 维度 | 通过 |
|---|---|---|---|
| 查询准确性 | 8/8 | 政策问答 | 6/6 |
| 意图理解 | 10/10 | 开放问答 | 4/4 |
| 多轮记忆 | 7/8 | 边界异常 | 5/5 |
| 忠实度 | 8/8 | 安全对抗 | 5/5 |

```bash
python eval/run_eval.py --cases eval/cases_v2.jsonl           # 全量
python eval/run_eval.py --category 查询准确性,政策问答         # 按维度
```

剩下 1 条（多轮换学校）暴露的是：当部分学校有数据、部分没有分数时，模型会外推"所有普通本科工科都 ≥12 分"这类统计结论。已知未修 —— 护栏只管"有没有查库"，管不了"查完之后再编"。

## 已知限制

- **会话存在内存里**：重启服务就丢。要真正产品化，得把会话落库，内存降级为缓存。
- **只能单实例跑**：会话不共享，不能直接扩多个 worker。
- **政策语料只有 18 个片段**：检索用的是内存向量 + 余弦相似度，语料再大会需要向量库。
- **凭证就是身份**：签名能防伪造，但挡不住"凭证被完整偷走" —— 那需要真正的登录系统。

## 数据来源

《内地高校招收香港中学文凭考试学生指南（2026/27 学年）》，官方发布。

本项目只做结构化解析与检索，不修改原始数据；每一条记录都能回溯到指南的书页页码。
