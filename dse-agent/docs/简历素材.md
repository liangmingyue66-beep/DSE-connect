## 一、项目条目（可直接放到简历「项目经历」）

### DSE 志愿填报助手 ｜ AI Agent 应用 ｜ [你的 GitHub 链接]

**技术栈**：Python、FastAPI、LangGraph（ReAct）、LangChain、PostgreSQL、RAG、SSE、Vue 3

**项目简介**：面向香港 DSE 考生的内地升学志愿填报助手，将《内地高校招收 DSE 学生指南》PDF 转为可对话查询的数据服务，覆盖 165 所高校、3794 条专业记录。

**一、并发与异步改造**：针对并发请求互相拖慢的问题（单独 2–3s，并发时先发的被拖到 6.3s），定位为 LangGraph 同步节点中的 LLM 调用阻塞事件循环，改为异步 `ainvoke` + 工具调用线程池化；用固定延迟假模型隔离上游 API 抖动后验证，两条并发由 3.00s 降至 1.51s。改造中连带发现同步 `invoke` 无法驱动异步节点、多事件循环导致连接池失效两个问题，回归 32 条全部通过。

**二、查询准确性与防编造**：针对大模型在录取分数上易算错、易编造的问题，采用「确定性工具 + 模型转述」的分层架构——数据经三层校验入库，查询时模型只输出结构化参数，筛选排序全部由参数化 SQL 完成；并设计护栏，在「问分数却未查库、却给出具体分数」时强制重查，对抗类用例通过率由 1/4 提升至 4/4。

**三、政策问答忠实性**：针对模型倾向用训练记忆回答政策问题、输出错误数字并伪造出处的问题，构建带原文出处的政策 RAG，并以提示词约束与护栏强制「必检索、只依据原文」；依据检索相似度的实测分布（相关组 0.588–0.769 与无关组 0.375–0.652 完全重叠）放弃绝对阈值，改为低置信标注 + gap 截断，避免把弱相关条文当作权威结论。

**四、多轮条件继承与结果呈现**：针对多轮对话中条件继承易污染、以及结果集过大导致信息不可用的问题，设计分层记忆（模型只输出本轮增量，代码维护精确状态，实体切换时清理冲突条件）；结果集过大时改为跨院校抽样概览 + 引导用户补充关键条件，而非罗列全量。

**五、评测体系**：针对 LLM 应用行为难以验证的问题，构建覆盖查询准确性、意图理解、多轮记忆、忠实度、政策问答、边界异常、安全对抗的评测集，全部用确定性断言（工具是否调用、是否泄漏具体分数、是否命中关键词）做回归，不依赖 LLM 打分。

**六、缺陷定位与修复闭环**：通过失败用例归因，定位并修复「政策未强制检索」「防编造护栏误伤政策问题」「多轮换实体未清理旧条件」「参数取值越界」等多类缺陷，逐条归因到模型 / 提示词 / 数据 / 检索 / 工程五层；对抗类用例通过率由 1/4 提升至 4/4，政策问答 4/6 → 6/6。

**可以放心写进简历的量化项**：165 所 / 3794 条 · 并发 3.00s → 1.51s · 对抗用例 1/4 → 4/4 · 政策问答 4/6 → 6/6

## 二、面试官一定会追问的问题（提前准备答案）

| 追问 | 你的答案要点 |
|---|---|
| 为什么分数不用模型直接答？ | 模型会编（实测出现过 434→454、把"4所志愿"编成"8个"）；分数是精确数据，必须走确定性 SQL，模型只负责转述 |
| 为什么用 ReAct 而不是固定工作流？ | 用户表达千差万别（"北京呢""去掉分数限制"），固定流程覆盖不全；ReAct 让模型自主决策，同时用确定性工具兜底 |
| 护栏怎么防编造？ | answer_guard：检测"用户问分数 + 没调查询工具 + 回答有具体分数" → 强制重查（最多 2 次）；局限是"查了库但夹带私货"拦不住，需逐字比对（未做，可讲改进方向） |
| 多轮怎么记住条件？ | memory.last_slots 增量继承：模型只填本轮新增（"北京"），其余由代码从记忆补全——不让模型回忆历史，避免抄错 |
| 流式怎么做的？踩过什么坑？ | LangGraph astream + SSE；坑是同步 stream 在 async 函数里会缓冲，事件全挤到最后（实测 118 个事件同一时刻到达），换 astream 后逐条 |
| 为什么参数用数组？ | 多值（多校/多专业）用数组，模型做语义拆分；代码不做分隔符猜测（顿号/空格/和 猜不完），Pydantic 校验失败返回模型重试 |
| RAG 怎么做的？ | 按 `##` 切片 → DashScope embedding → 余弦相似度 top-k → 带出处；不足：语料仅 3 份，覆盖有限 |
| 怎么保证数据准确？ | 数据来自 PDF 入库管线（非手输）+ SQL 确定性查询 + 评测回归；抽检与网页比对 |
| 项目最大的难点？ | 在"让模型自由"和"数据必须准"之间划线：最终是"ReAct 外壳 + 确定性工具内核 + 护栏" |
| 如果让你继续做，会改什么？ | ①政策问答"依据原文"校验（防夹带私货）②数据补齐 11 校 ③token 级流式已做、可加中断 ④多用户会话持久化（现为内存） |
